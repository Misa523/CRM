# Moje CRM

Jednoduché osobní CRM: kontakty, obchody (pipeline), úkoly a faktury.

## Jak spustit
Dvakrát klikněte na `index.html`, otevře se v prohlížeči. Nic se neinstaluje.

## Kde jsou data
Jen v prohlížeči, ve kterém aplikaci používáte. Zálohu stáhnete v **Nastavení → Stáhnout zálohu**.
Stejným souborem data přenesete i na jiné zařízení (**Obnovit ze zálohy**).

## Synchronizace mezi zařízeními
Postup nastavení cloudu (Supabase) a webové adresy (GitHub Pages) je v [NAVOD-CLOUD.md](NAVOD-CLOUD.md).

## Jak udělat úpravu
Otevřete tuto složku v Claude Code a napište, co chcete změnit, třeba:
- „Přidej ke kontaktu pole web a datum narození.“
- „Ve fakturách chci vidět i DPH.“
- „Přidej fázi obchodu Čeká na podpis.“
